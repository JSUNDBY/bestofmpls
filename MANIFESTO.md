# bestofmpls — Manifesto

The canonical strategy doc. DESIGN.md is the visual rulebook;
this is the *why*. Every decision the site makes should ladder back to
this. Read it before doing anything substantial.

---

## Core positioning

Best of MPLS is NOT:

- a local magazine
- a tourism board
- a lifestyle publication
- an SEO city guide
- an Eater clone
- "Minneapolis luxury"

It should become:

> A civic-cultural operating system for Minneapolis and Saint Paul.

The site should feel:

- public
- lived-in
- infrastructural
- emotionally intelligent
- weather-aware
- movement-oriented
- culturally literate
- human
- socially grounded

Closer to:

- transit systems
- public radio
- library systems
- venue calendars
- park infrastructure
- neighborhood institutions

Than to:

- magazines
- blogs
- luxury editorial brands

---

## Design direction

**Scandinavian municipal noir**, but NOT winter fetishism. The site
should metabolize the current season.

Right now (spring/summer) that means:

- warm pavement
- patio season
- bikes
- river walks
- late sunsets
- Northeast energy
- baseball
- humid dusk
- music spilling into the street

Avoid:

- dark moody noir clichés
- cinematic over-stylization
- fake grit
- luxury minimalism
- boutique hotel energy

### Visual goals — the site should communicate

- public-space feeling
- civic infrastructure
- urban movement
- weather + time awareness
- neighborhood energy
- cultural density
- calm confidence

### Visual non-goals — the site should NOT feel

- overdesigned
- influencer-oriented
- startup-polished
- ad-driven
- suburban-professional
- luxury regional media

### Typography

Move toward: grotesk-heavy systems, infrastructural hierarchy, transit
typography, signage logic, civic labeling, compressed utility type.
Possible references: Neue Haas Grotesk, ABC Diatype, Söhne, Akzidenz,
Inter Tight, Suisse Intl. (Current stack: Archivo Narrow marquee, IBM
Plex Sans display, IBM Plex Mono numerals, Source Sans body. Reads in
that tradition.)

Move away from: serif-heavy systems, literary/editorial elegance,
italics as emotional tone.

### Visual principles

**LESS:** obvious cards, floating luxury UI, overly balanced layouts,
magazine pacing, perfect spacing everywhere, lifestyle imagery,
"premium" visual language.

**MORE:** system graphics, overlays, transit cues, directional markers,
weather indicators, operational asymmetry, district labeling,
utility-beauty, public-space rhythm.

Asymmetry should come from **utility, density, city behavior, weather,
timing, neighborhood activity** — not random art-direction
experiments.

## Things to build next

### 1. Stronger homepage system identity
The homepage should feel like a city dashboard / transit kiosk /
cultural radar / civic interface. Not a magazine homepage. Potential
additions: weather layer, sunset layer, neighborhood pulse, district
markers, live city-state indicators, "where the energy is tonight."

### 2. Signature recurring UI behavior
The neighborhood-code tag is now this. Don't dilute it. Future
additions in the same register: route markers, sunset countdown strip,
ambient density indicators, oversized NOW blocks. Must feel
infrastructural and repeatable, never gimmicky.

### 3. Reduce cardness
Visible boxes give the site SaaS / app / content-platform energy.
Need embedded surfaces, layered layouts, infrastructural composition,
environmental integration. Tool-card grid is the next thing to kill.

### 4. Deepen environmental awareness
The site should increasingly understand: weather, light, season, time
of day, neighborhood activity, patio viability, event density,
late-night energy. Minneapolis changes dramatically by season and
sunlight; the interface should reflect that.

### 5. Mobile feels operational
Persistent bottom dock with Tonight / Calendar / Map / Near / Menu —
already shipped. Future: Saved, route building, geofenced nudges.
Mobile should feel like navigating the city, not reading pages.

### 6. Maps become central
Future moat = spatial discovery, movement, neighborhood transitions,
emotional geography. Not articles. The map page should become a true
operating system, not a Leaflet pin layer.

cultural transit, neighborhood intelligence, social-density awareness,
memory archive, real-time urban discovery.

Eventually:

- "quiet solo night"
- "walkable date route"
- "where artists are tonight"
- "rainy-night Minneapolis"
- "good low-cost Saturday"
- "where the city is alive tonight"

## Monetization

**DO NOT:** run generic ads, become MSP Magazine, do
dentist/doctor/spammy sponsorships, become SEO media.

**DO:** civic sponsorships, memberships, seasonal city guides,
curated ticketing, city packs, neighborhood maps, cultural
memberships, trusted recommendations.

Monetization should feel useful, integrated, civic, trusted — not
ad-driven.

---

## North star

The project should feel like:

> a beloved cultural utility for Minneapolis

NOT:

> a publication trying to monetize attention.

That distinction guides every design and product decision.
